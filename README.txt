# NovaTech Company Website — Lab 2

## Files
- `index.html` — Home page
- `about.html` — About page
- `products.html` — Products table
- `contact.html` — Contact form with HTML validation attributes
- `style.css` — Shared responsive styling

## Test locally
Open `index.html` in a web browser. Use the navigation menu to visit all four pages.

## Validate HTML
For each HTML file, open https://validator.w3.org/ and upload the file or paste its source. Fix any errors reported by the validator.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `company-website`.
2. Upload all five website files to the repository's root folder.
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)` folder, then save.
6. Wait for GitHub Pages to publish the site. Copy the published URL.

## Lab submission
Submit:
- The published multi-page website URL.
- A screenshot of the clean validation report.

Note: NovaTech and the product prices are fictional examples. The contact form performs browser-side validation only; it does not send data to a server.
